ОНОВЛЕННЯ ДО ПОВНОЇ ВЕРСІЇ ЗАВДАННЯ (SearchBar / MovieGrid / Loader /
ErrorMessage / MovieModal)

--------------------------------------------------------------------
КРОК 1. Замінити папку src
--------------------------------------------------------------------
Видали стару папку src у своєму репозиторії й постав цю (з архіву).
Стара містила MovieCard/MovieList/api.ts — вони більше не потрібні,
нова папка їх не має. Файл .env у корені НЕ чіпається (він поза src).

--------------------------------------------------------------------
КРОК 2. Оновити React до 19 і поставити нову бібліотеку
--------------------------------------------------------------------
Завдання вимагає Form Actions (<form action={fn}>) — це можливість
React 19. Твій проєкт зараз на React 18, тому онови. У терміналі,
у папці проєкту (де package.json), виконай:

  npm install react@19 react-dom@19
  npm install -D @types/react@19 @types/react-dom@19
  npm install react-hot-toast

Модальне вікно зроблено через createPortal (react-dom) — окрема
бібліотека react-modal НЕ потрібна.

--------------------------------------------------------------------
КРОК 3. Перезапустити сервер
--------------------------------------------------------------------
  Ctrl+C  (зупинити старий)
  npm run dev

Відкрий сторінку, введи "batman":
- має з'явитись сітка постерів (MovieGrid);
- порожній пошук -> тост "Please enter your search query.";
- пошук без результатів -> тост "No movies found for your request.";
- клік на картку -> модальне вікно (закриття: хрестик / Esc / клік по фону).

--------------------------------------------------------------------
КРОК 4. Перевірити й запушити
--------------------------------------------------------------------
- Внизу VS Code "Проблеми" має бути 0.
- git status -> .env у списку бути НЕ повинно.
- git add . && git commit -m "Implement movie search app" && git push

SETUP.md у репозиторій класти не обов'язково.
